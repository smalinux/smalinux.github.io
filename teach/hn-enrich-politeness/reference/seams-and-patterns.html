Ports & Adapters (Hexagonal) A one-method Protocol in front of each external effect; the rest of the code depends on the shape, not the client. ports.py — HttpFetcher, TrackerScanner, AiClassifier Swap real ⇄ fake at one seam; no internal call-sequence mocking. 0003
Decorator over a Port An object that is-a and has-a the same port, adding behaviour around the inner call. politeness.py — PolitenessFetcher, PolitenessScanner Cross-cutting policy testable over a fake; reused across every port that shares the interface. 0003
Dependency Inversion The policy owns the abstraction; the machinery depends on it. Arrow points toward the policy. ConcurrencyGate defined in politeness.py, filled by limits.py politeness.py never imports Prefect; its tests start no server. 0001
Functional Core, Imperative Shell A pure, total function decides and returns a verdict as data; a thin shell performs the injected effect. limits.py (plan_limits → deploy_init), teardown.py (plan_teardown → destroy_enrich) The hard logic tests with literals; the shell is too small to hide a bug. 0004
Null Object A do-nothing implementation of a seam, so callers need no null check. politeness.py — _open_gate returns nullcontext() Politeness works with no capacity system at all; no if gate is None. 0001
Service Locator One place resolves every dependency; an override seam installs fakes for a block. deps.py — accessors + override / reset Prefect tasks keep plain-id parameters. An honest step down from constructor injection (its docstring says so). 0003

Anti-patterns — what these moves are chosen to avoid

SmellWhat breaksThe move that avoids it
Decision welded to effect — one function both decides and acts. The decision is testable only by its effect; to check a guard you must risk the drop. Functional Core, Imperative Shell (0004)
Check-then-use across a boundary — validate here, act past the seam. The thing changes in the window (DNS rebinding); the guard leaves no witness. Move the control to the layer that acts — egress proxy (0002)
Policy inlined into a client — the if baked into the real fetcher. Shallow, entangled module; every test drags the transport; rules get copied and drift. Decorator over a Port (0003)
Pass-through wrapper — a layer that forwards unchanged. A new layer with no new abstraction: pure cost (Ousterhout). Only decorate when the wrapper does real work (0003)
A cap that exists only sometimes — silently run un-capped if unset. A run against an unconfigured server hammers targets with no limit. strict=True raises instead (0001, limits.py)
