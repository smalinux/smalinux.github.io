The fetch-path boundary map

Reference · who owns what on hn-enrich's live-fetch path · verified against the tree at 2026-07-17

The test

AskIf yes
Can I answer it from the url alone? politeness.py
Does it count how many at once, or relate two capacities? limits.py
Is it a transport detail (User-Agent, timeout, http verb)? adapters.py
Is it which implementation gets used (real vs fake)? deps.py
Is it the shape of an external effect? ports.py

The line: politeness.py knows there is a gate, but not how wide. limits.py knows how wide, but not when you will open it.

The wiring

   worker ──asks for──▶ deps.fetcher()          "just give me a fetcher"
                             │
                             ▼
        PolitenessFetcher(inner, limiter=…, gate=live_fetch_gate)
              │                  │                     │
              │                  │                     └── limits.py  (capacity)
              │                  └── RateLimiter        shared: one per process
              │
              └── HttpxFetcher   (transport: UA, timeout, one hop)
                       │
                       └─drives─▶ walk_redirects(...)   (politeness owns the walk)

   import arrow:   limits.py ──▶ politeness.py          (never the reverse)
   both are HttpFetcher-shaped, so they compose at the same seam (ports.py)

politeness.py — per-call policy

NameIs
is_public_url / assert_public_urlThe SSRF guard. Scheme must be http(s); localhost refused; IP literal judged directly; hostname resolved and every address judged. Fails closed.
Resolver / default_resolveHow a name becomes addresses. Injectable, so DNS policy is tested without a socket. Asks for every family (A + AAAA).
walk_redirectsThe redirect rule's one home. Guards every hop before fetching it. Adapters supply a one-hop fetch_once and must never follow redirects themselves.
RateLimiterPer-domain minimum spacing. Reservation stamped under a lock; the sleep happens outside it.
ConcurrencyGateThe shape of a gate: something you can stand inside. Defined here, filled in by limits.
PolitenessFetcher / PolitenessScannerDecorators over HttpFetcher / TrackerScanner. Both run _politeness, so the two live-fetch paths cannot drift.

The order inside _politeness is load-bearing: guard → space → gate. The guard is cheapest and refuses before any effect; the gate is held only around the real call, so a refused url never burns a slot.

limits.py — system capacity

NameIs
plan_limitsPure. The two caps, in order: live-fetch then reprocess.
reprocess_bounded_below_livePure. The invariant: reprocess < live-fetch, so heals never starve fresh enrichment. Config floors each at 1; only this relates them.
apply_limits / deploy_initThe thin effect. upsert is injected → tests never reach Prefect. Refuses before touching the store if the invariant breaks.
live_fetch_gate / reprocess_gateThe real gates. strict=True → raises if the limit was never registered, rather than silently running un-capped.

Invariants to re-apply in any rebuild

#InvariantWhy it is stated this way
1 Every redirect hop is guarded before it is fetched — not just the url the fetcher was handed. A guard on the first url only is bypassed by any public url that redirects inward. An adapter with follow_redirects=True behind a wrapper-only guard is the bug — and it leaves no witness.
2 A hostname is judged by what it resolves to, and by every address, across every family. A public-looking name backed by a private IP is otherwise accepted. Matches OWASP: retrieve A + AAAA and apply the same verification to all.
3 Fail closed. No resolution, empty resolution, or one bad address ⇒ refuse. The default answer to "I don't know" must be no.
4 A cap that exists only sometimes is the bug. strict=True. A run against a server where deploy-init never registered the limit must fail loudly, not run un-capped.
5 reprocess < live-fetch, enforced before anything is written. A bad .env must not be able to register a self-starving pipeline.
6 One shared policy behind both live-fetch wrappers; one shared limiter across every adapter. Two copies drift. Per-domain spacing must hold across workers, not per wrapper.

The known edge

Not fixable inside this module

The guard resolves a name, judges it, then passes the url onward — and the transport resolves it again. Between the two lookups the answer can change (DNS rebinding; check-then-use). OWASP flags this directly. Closing it needs something outside the process: an egress proxy (Smokescreen) plus egress rules. Hence: politeness.py is frozen, and the real tracker scanner must not ship before those land.
